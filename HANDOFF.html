媒体放大技能包
Media Upscale Skills

图片放大 Upscayl × 视频放大 Topaz —— 部署 · 验证 · 调用全说明
面向 其他 AI 工具 / 新电脑 包体 < 100 KB（仅脚本+文档） 交接日期 2026-11-19 环境 Windows + NVIDIA GPU

一套纯命令行封装的两套 AI 放大能力。包里只有脚本和文档，不含软件本体与模型——部署机需先装好 Upscayl 桌面版和 Topaz Video AI。脚本采用「环境变量 → 自动探测 → 默认路径」三级路径解析，换机器一般零改动。所有固定值与踩坑均为原机 2026-07 ~ 2026-09 实跑验证。

0. 技能一览

技能用途触发词
upscayl-batch图片放大（阿普升图），固定 2 倍 PNG 无损放大图片 / Upscayl / 阿普升图 / 批量放大
topaz-video-x4视频放大（Topaz），1080P/2K/4K 三档或 4 倍Topaz 放大 / 视频超分 / 出 4K / 视频 4 倍

1. 依赖清单（部署机必须满足）

依赖用途自检
Windows + PowerShell 5.1 或 7运行 .ps1$PSVersionTable.PSVersion
Upscayl 桌面版（upscayl-bin.exe + resources/models）图片放大自检脚本第 1 段
Topaz Video AI 6.x（自带 ffmpeg/ffprobe + prob-4 模型）视频放大自检脚本第 2 段
NVIDIA 显卡 + 驱动（原机 RTX 3070 Ti）两者都用 GPUnvidia-smi
没有这些软件时先装软件。脚本本身不含推理引擎和模型权重，无法替代软件。

2. 部署五步

1
下载解压到无中文、无空格路径，如 C:\tools\media-upscale-skills。
2
运行自检 powershell -ExecutionPolicy Bypass -File check-env.ps1，目标是 Upscayl / Topaz / GPU 三段全 OK。
3
出现 MISS：软件在非常规盘就改 set-env.example.ps1 设环境变量；模型缺失就在软件里确认已下载（Topaz 的 prob-4.json、Upscayl 的 ultrasharp-4x）。
4
把 upscayl-batch/ 和 topaz-video-x4/ 复制到目标 AI 工具的技能目录；各技能靠自身 SKILL.md 的 frontmatter 被识别触发。
5
冒烟测试：图片用 1 张小图跑一次；视频用几秒短片跑 -Preset 1080p，确认按固定分辨率出片。

3. 调用契约

3.1 图片放大

# 基本（默认输出到 输入\upscaled_2x）
powershell -ExecutionPolicy Bypass -File upscayl-batch\upscayl-batch.ps1 -InputDir "图片文件夹"

# 指定输出 + 2 个并行
powershell -ExecutionPolicy Bypass -File upscayl-batch\upscayl-batch.ps1 -InputDir "输入" -OutputDir "输出" -Workers 2

支持 png/jpg/jpeg/webp，统一出 .png；断点续跑：已有同名 png 自动跳过；路径解析优先级 -Exe/-Models 参数 > 环境变量 > 自动探测。Git Bash 用户可用 .sh 版。

3.2 视频放大

# 默认 all = 一次出 1080P + 2K + 4K 三份
powershell -ExecutionPolicy Bypass -File topaz-video-x4\topaz-video-x4.ps1 -Preset all "视频.mp4"

# 单档：1080p / 2k / 4k ；4 倍：x4
powershell -ExecutionPolicy Bypass -File topaz-video-x4\topaz-video-x4.ps1 -Preset 4k "视频.mp4"

输出落在源视频同目录，加后缀 _1080p/_2k/_4k/_x4。AI 调用不要加 -WaitAtEnd（会卡住等回车），只有 .bat 拖拽入口才加。成功判据：打印 RESULT_PATH=... 且 ffprobe 读回宽高与期望一致。

4. 固定规则（不可改，已实测）

项固定值
图片参数2 倍 / PNG 压缩 0 无损 / ultrasharp-4x / TTA 关 / GPU 0；单张循环比整目录喂更快（63s vs 98s，同 3 张图）
视频三档1080P=1890×1080、2K=2520×1440、4K=3780×2160（按源片 7:4 定，不是 1920/2560/3840）
视频模型/环境变量prob-4；必须是 TVAI_MODEL_DIR（写错报 Model not found）
编码宽或高 ≤4096 → h264_nvenc high；4097~8192 → hevc_nvenc main（HEVC 不能写 high）；>8192 跳过
声音-c:a copy 原样拷贝

5. 踩坑清单（接手前必读）

图片线

  1. 盘符搞混：Upscayl 常在 F 盘，图片在 C 盘，传路径确认盘符。
  2. 中文/空格/括号路径加双引号，否则 shell 解析失败。
  3. 别重装、别从 GitHub 下 Upscayl，复用本机已装桌面版。
  4. 参数名版本差异：--help 里倍数可能显示 -z，实际用 -s 正常。
  5. .ps1 编码：含中文必须 UTF-8 带 BOM；本包脚本源码刻意纯 ASCII（中文目录用 [char] 码点拼），改动请保持。
  6. job 传参：Start-Job 里 $using: 传对象会取空；本包改传字符串路径数组已规避。
  7. 估时长先测显存：空闲约 18s/张，显存被挤占劣化到 42~109s/张（差 6 倍）。
  8. 整批前先筛源尺寸：已达标的图会被二次放大成 4 倍，需预先筛掉。

视频线

  1. 环境变量名写错 = 找不到模型（最高频），只认 TVAI_MODEL_DIR。
  2. 必须用 Topaz 自带 ffmpeg，系统 ffmpeg 没有 tvai_up 滤镜。
  3. 指定分辨率用 scale=0 + 写死宽高；4 倍用 scale=4 + 写死 4 倍宽高。
  4. HEVC 误写 -profile:v high 会先报错，易误判成模型坏。
  5. 三档是 1890/2520/3780，别改成 1920/2560/3840。

交接 2026-11-19 本包脚本相对原机唯一改动 = 路径解析通用化 + 源码纯 ASCII 化 + bat 路径改相对；核心调用参数与执行循环保持原样，自检与冒烟测试通过。

7. 不要做的事

  • 不要把软件本体、模型打包进技能包（体积爆炸且涉及授权）。
  • 不要宣称成功却不核验：图片看尺寸是否翻倍、视频用 ffprobe 读回宽高，空文件/原分辨率 = 失败。
  • 不要改成云端模型 / 第三方权重 / 普通 scale 插值充数。
